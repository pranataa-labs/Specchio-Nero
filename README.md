# Operation Specchio Nero

> CLASSIFICATION: RESTRICTED // EYES ONLY  
> DIRECTIVE: RECRUITMENT INITIATIVE 2026-B  
> CLEARANCE REQUIRED: LEVEL 4  

Unit Forensik Digital menyita sebuah berkas citra restorasi resolusi tinggi dari *workstation* seorang kurator arsip di Florence yang diduga menyelundupkan dokumen rahasia menggunakan teknik komunikasi klandestin.

Kami mencari individu dengan kemampuan di atas rata-rata. Jalan menuju tahap berikutnya tersembunyi di dalam kanvas.

### Protokol Operasional

1. Integritas rantai bukti (*chain of custody*) adalah mutlak. Verifikasi SHA-256 sebelum melakukan analisis.
2. Tidak ada petunjuk publik tambahan yang akan dirilis.
3. Kunci verifikasi tahap berikutnya berupa kode *cryptographic hash* 256-bit.
